درباره ما

وب‌سایت «آزاد اندیشان» یک پلتفرم تک‌صفحه‌ای و کاملاً تعاملی است که با هدف نمایش پروژه‌های دانشجویی، خدمات پژوهشی و پایان‌نامه طراحی شده است.

این سایت با استفاده از تکنولوژی‌های روز مانند Tailwind CSS و JavaScript خالص ساخته شده و امکاناتی مانند جستجو و فیلتر پروژه‌ها، ثبت نظر کاربران، پاسخ‌دهی مدیر، نمایش ساعت و تاریخ هوشمند، و منوی همبرگری زیبا را فراهم کرده است.
